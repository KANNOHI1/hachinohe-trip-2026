**Day2（2026/9/21）の中心=龍泉洞は再開した。残るリスクは「開くか」ではなく「濁っていないか」。**

- 経緯: 2026/8/12 の台風15号で1.3m以上増水し通路が冠水 → 閉洞。洞内の清掃・点検を経て **2026/8/22（土）8:30 営業再開**（公式お知らせ 8/21付・10日ぶり）。営業時間は 8:30〜18:00 に復帰
- **公式は透明度について何も告知していない**（再開告知・トップ「今日の龍泉洞」ともに水質の記載なし＝濁りが残っているか回復済みかは公式情報からは判断できない）
- **開いていても濁っていれば行く価値が薄い**。龍泉洞の価値はほぼ地底湖の透明度。2023年の前例は 8/14閉洞 → 9/2再開（約3週間）で、再開時点で公式が「透明度が落ちており回復に数週間」と明示していた。2026年は再開が10日と早い分、**再開時点の水質は2023年より悪い可能性がある**
- 2026年は再開から Day2 まで約30日ある。2023年前例の「再開＋数週間」に照らせば間に合う公算が高いが、**確証は取れていない**
- 追跡先: 公式サイト https://www.iwate-ryusendo.jp/ と X @Ryusendo_iwate。**直前に TEL 0194-22-2566 で「地底湖の透明度は戻っているか」を直接聞くのが唯一確実**。9月の開洞は8:30〜18:00なので13:30入洞に時間的論点はない
- **代替案**: 濁ったままなら Day2 は櫛引八幡宮を朝ゆっくり回し、南下の道中（北山崎など三陸海岸）へ時間を振る。**宿（ホテル龍泉洞愛山・龍泉洞至近）は9/18から取消料が発生するため動かさない**
- 判断タイミング: **9月上旬〜中旬にTELで透明度を確認**（9/18の取消料発生前に結論を出す）
